mysteam

Telegram-бот, который публикует в канал игры Steam с торговыми карточками, то есть игры для значка коллекционера. Публикуются бесплатные раздачи и скидки от 30%.

Как это работает
Бот берёт кандидатов из витрины Steam (раздел featuredcategories).
Для каждой игры запрашивается страница в Steam Store (appdetails), и проверяется наличие категории «Steam Trading Cards».
Игры без карточек пропускаются.
Найденные игры собираются в один HTML-пост и отправляются в Telegram-канал.
ID проверенных игр сохраняются в posted_games.json, чтобы не проверять и не публиковать их повторно.

Если подходящих игр за запуск не нашлось, пост не отправляется.

Настройки в bot.py
Константа	По умолчанию	Описание
MAX_FREE	5	Максимум бесплатных раздач в одном посте
DEALS_PER_POST	3	Максимум скидок в одном посте
MIN_DISCOUNT	30	Минимальная скидка в процентах
MAX_CANDIDATES_TO_CHECK	30	Сколько игр проверять за один запуск
REQUEST_DELAY	1.5	Пауза между запросами к Steam, в секундах
DISCOUNTS_EVERY_HOUR	True	Если False, скидки публикуются только в 08:00 и 14:00 МСК (05:00 и 11:00 UTC)
MAX_HISTORY_SIZE	400	Сколько последних ID хранить в истории
Требования
Python 3.10 или новее
Библиотека requests

Установка зависимостей:

bash
pip install -r requirements.txt
Переменные окружения

Бот читает два секрета:

BOT_TOKEN — токен бота от @BotFather
CHANNEL_ID — ID или username канала. Можно указать @channel_name, channel_name, ссылку вида https://t.me/channel_name или числовой ID (например, -1001234567890)

Бот должен быть администратором канала с правом публикации сообщений.

Запуск в GitHub Actions

Секреты добавляются в Settings → Secrets and variables → Actions:

BOT_TOKEN
CHANNEL_ID

Бот запускается по расписанию раз в час. Файл posted_games.json должен коммититься обратно в репозиторий после каждого запуска, иначе история будет теряться и посты начнут повторяться.

Локальный запуск
bash
export BOT_TOKEN="123456:ABC..."
export CHANNEL_ID="@my_channel"
python bot.py

В Windows (PowerShell):

powershell
$env:BOT_TOKEN="123456:ABC..."
$env:CHANNEL_ID="@my_channel"
python bot.py
Структура проекта
mysteam/
├── bot.py              # основная логика бота
├── posted_games.json   # история проверенных и опубликованных игр
├── requirements.txt    # зависимости
└── .github/workflows/  # расписание запуска в GitHub Actions
Ограничения
В витрине Steam в каждый момент может быть мало игр с карточками, поэтому посты выходят не каждый час.
Steam Store API не документирован, и его формат может измениться.
Бот не проверяет, что игра доступна в вашем регионе. Цены берутся для cc=ru.
